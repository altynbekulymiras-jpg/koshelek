# Перевод комментариев TikTok LIVE: казахский → русский

Программа подключается к прямому эфиру TikTok по нику стримера, читает комментарии
и сразу переводит казахские на русский.

## Установка (один раз)

1. Установите Node.js 18 или новее: https://nodejs.org
2. Откройте терминал в этой папке и выполните:
   ```
   npm install
   ```

## Запуск

```
node index.js ник_стримера
```
(ник берётся из ссылки `tiktok.com/@ник/live`, знак `@` можно не писать.
Стример должен быть в эфире.)

Переводы появляются в окне терминала: сначала перевод, ниже серым цветом оригинал.

## Оверлей для OBS / TikTok LIVE Studio

Пока программа работает, откройте в браузере **http://localhost:3000**.
Можно добавить этот адрес как источник «Браузер» (Browser Source) в OBS или
TikTok LIVE Studio. Фон прозрачный, на экране последние 8 комментариев.

## Настройки

| Переменная | Что делает |
|---|---|
| `ONLY_KAZAKH=1` | показывать только казахские комментарии, остальные скрывать |
| `TARGET_LANG=en` | перевод на другой язык (по умолчанию `ru`) |
| `PORT=3001` | другой порт для оверлея |

Пример (Windows PowerShell): `$env:ONLY_KAZAKH=1; node index.js ник`
Пример (macOS/Linux): `ONLY_KAZAKH=1 node index.js ник`

## Ограничения

- Чат читает неофициальная библиотека `tiktok-live-connector`. Если TikTok что-то
  поменяет, может понадобиться `npm update`.
- Переводит бесплатный Google Translate. Сленг и смешанную казахско-русскую речь
  он иногда переводит неточно, поэтому оригинал всегда показан под переводом.
